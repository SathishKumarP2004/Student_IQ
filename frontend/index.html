About StudentIQ

Understanding the system, methodology, and technology behind the predictions

Explainable Machine Learning for
Identifying Inconsistent Student Performance

A final year research project that combines advanced classification algorithms with interpretable AI techniques to detect and explain irregular patterns in student academic data.

How It Works

1
Data Collection — Student records across multiple semesters including GPA, attendance, scores, and extracurricular activities are aggregated into feature vectors.
2
Feature Engineering — 17 statistical features are computed: means, standard deviations, trends, correlations, and behavioral indicators.
3
ML Classification — Three models (Random Forest, XGBoost, Logistic Regression) classify students as consistent or inconsistent performers.
4
SHAP Explanation — SHAP values reveal which features contributed most to each prediction, making the AI decision transparent and interpretable.

Research Context

This system addresses a critical gap in educational analytics: the inability to explain why an ML model flags a student as inconsistent. Traditional approaches treat models as black boxes, but StudentIQ provides full transparency through SHAP-based explanations.

By combining high-accuracy ensemble methods with interpretable AI, educators can make informed, data-driven decisions about student interventions while understanding the reasoning behind each recommendation.
